## Установка и запуск

```bash
npm i
npm start
```

## Скрипты

| Команда          | Описание                                       |
| ---------------- | ---------------------------------------------- |
| `npm start`      | Запуск в режиме development (через nodemon)    |
| `npm run build`  | Запуск в режиме production                     |
| `npm run deploy` | Запуск в режиме domain                         |
| `npm run use`    | Демонстрация работы кастомных модулей (use.js) |

## Структура проекта

```
L8_NodeBase/
  index.js              -- главная точка входа
  use.js                -- использование кастомных модулей
  src/
    studentInfo.js      -- вывод данных студента из .env
  os/
    index.js            -- работа с модулем OS
  fs/
    index.js            -- функции файловой системы (sync + async)
  modules/
    bcrypt.js           -- шифрование паролей через bcrypt
  custom/
    sortStrings.js      -- сортировка строк без учета пробелов
    fetchData.js        -- загрузка данных (fetch-обертка)
    fileSystem.js       -- модуль-обертка для fs-функций
```

## Разделы работы

1. **Первые шаги** -- dotenv, переменные окружения, вывод информации о студенте.
2. **Модуль OS** -- информация об ОС, проверка свободной памяти, контроль доступа по MODE.
3. **Файловая система** -- 10 функций для работы с файлами и директориями в синхронном и асинхронном вариантах (без потоков).
4. **Модули npm** -- nodemon для авто-перезагрузки, bcrypt для параллельного шифрования 13 паролей, cross-env для переключения между .env файлами.
5. **Кастомные модули** -- сортировка строк, загрузка данных с JSONPlaceholder, модуль файловой системы.
6. **use.js** -- загрузка пользователей, сортировка по именам, запись в файлы users/names.txt и users/emails.txt.

## Переменные окружения

Основные переменные задаются в файле `.env`:

```
FIRST_NAME=...
LAST_NAME=...
GROUP_NUMBER=...
STUDENT_NUMBER=...
MODE=admin
```

Режимы работы задаются в отдельных файлах:

- `.env.development` -- MODE=development
- `.env.production` -- MODE=production
- `.env.domain` -- MODE=domain
